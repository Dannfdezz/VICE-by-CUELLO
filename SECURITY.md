# Security policy

VICE v14 R2 is experimental. Previously reported VirusTotal results: source ZIP 0/65, launcher 4/69, installer 6/70. These detections have not been confirmed as false positives. Windows runtime validation and independent review remain pending. Do not disable antivirus protections. Review third-party engines and build scripts separately. Verify the source, signatures and SHA-256 before using any release. Report security concerns privately through GitHub if available. Binary releases are deferred pending review.
